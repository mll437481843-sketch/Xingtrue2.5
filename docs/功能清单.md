# 功能清单（已实现 / 未实现）

## 一、已实现

### 模块一 歌单批量下载
- 识别：标准链接、#/playlist、分享文本、纯 ID、专辑链接；无效链接明确报错
- 解析：名称、歌手、专辑、歌曲 ID、时长、封面、发布时间、可用性、序号；超 1000 首自动分批补全
- 列表：封面、标题、歌手、专辑、时长、音质标签、下载状态、勾选
- 操作：全选 / 全不选 / 反选 / 单曲勾选 / 按歌手筛选 / 关键词搜索 / 按下载状态筛选 / 仅未下载 / 加载更多
- 重复检测（同 ID 标「重复」）、可下载性批量核验、完整性统计（总数/已下载/重复/待核验）
- 批量下载：下载选中、跳过不可下载、按音质档位请求

### 模块二 单曲下载
- 多行批量输入（≤100 条），逐行识别、自动清参数、无效行单独列出原因
- 解析后展示：标题/歌手/专辑/封面/时长/可用性/实际音质/格式/是否已下载
- 下载选项：音质、歌词、封面、元数据开关；保存路径遵循全局设置
- 完成后可在任务页打开文件、重新下载

### 模块三 任务中心
- 状态机：等待中 / 解析中 / 下载中 / 暂停中 / 已完成 / 失败 / 已取消 / 无法获取
- 队列：并发上限（1~6）、暂停/恢复单任务、暂停/恢复整队列、取消、删除、清空已完成、重试失败
- 重试：网络类错误指数退避（1/2/4/8s，上限 15s），永久错误不重试，记录失败原因
- 实时：总进度、每任务进度/速度、全局速度、总任务/完成/失败计数
- 持久化：任务写入 SQLite，重启后恢复并把中断任务置为「已暂停」
- 断点续传：HTTP Range + .part 文件

### 模块四 文件与元数据
- 命名模板：{歌手} - {歌曲名称} / {歌曲名称} / {专辑} - {歌曲名称} / {歌手} - {专辑} - {歌曲名称} / {序号} - {歌手} - {歌曲名称}
- 非法字符替换、超长截断、同名冲突自动加序号
- 分类：不分类 / 按歌手 / 按专辑 / 按歌单 / 按日期
- 查重三级：平台歌曲 ID（数据库）、标题+歌手（目录扫描）、文件 MD5
- ID3v2.3 写入：TIT2/TPE1/TALB/TRCK/TYER/APIC/USLT，写前备份，失败回滚

### 模块五 歌词与封面
- LRC / TXT 保存，跟随歌曲名；获取失败只提示，不影响音频任务
- 封面保存 JPG/PNG（按实际字节判断），可内嵌到 MP3

### 模块六 本地音乐库
- 目录扫描 8 种音频格式，读取标题/歌手/专辑/时长/大小/格式
- 搜索、缺封面筛选、缺元数据筛选、同名重复检测（另有 MD5 精查接口）
- 点按交给系统播放器打开（FileProvider）

### 其他
- 首页：欢迎区、快捷入口、今日/累计下载、进行中、空间占用、当前任务、最近下载、权限提醒
- 历史：检索、打开文件、时间与大小
- 设置：下载/文件/外观/高级四组，含网络测试、日志查看、数据库备份、恢复默认
- 关于：数据来源与合规说明、运行信息、运行自检（7 项）
- 主题：深色 / 浅色 / 跟随系统；界面缩放 90%~120%
- 异常：统一错误提示、启动兜底页、空状态页、二次确认弹窗

## 二、未实现 / 受限（附原因）

| 项 | 状态 | 原因 |
| :-- | :-- | :-- |
| 会员/付费曲目下载 | 不实现 | 无官方下载接口；实现即等于绕过版权，需求明令禁止 |
| 无损音质稳定获取 | 受平台限制 | 匿名请求下平台极少返回 lossless 源，界面按实际返回展示 |
| 数据库恢复的文件选择器 | 简化 | 当前提供备份落盘 + 恢复接口，UI 未接文件选择器（需 SAF 交互） |
| 通知栏下载进度 | 未实现 | 需要前台服务与通知渠道，本轮优先保证单进程稳定 |
| 本地库内嵌封面缩略图 | 未实现 | 数量大时 base64 渲染卡顿，改为标记 + 单曲查看接口 |
| Windows 可执行程序 | 不适用 | 交付目标为 Android APK |
| 歌单「仅选择未下载」按服务器端判断 | 已实现为本地数据库判断 | 平台不提供该维度，本地判定足够准确 |
