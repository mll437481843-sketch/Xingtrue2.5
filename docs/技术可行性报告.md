# 技术可行性报告（第一阶段交付）

调研时间：2026-11-11 · 全部结论基于**本机真实请求**验证，非文档推测

## 一、调研方法

在本机用 Node 直接请求网易云音乐 Web 域名，记录 HTTP 状态、业务 code 与返回字段；随后把同样的调用写进 Kotlin 客户端，用桌面 JVM 跑同一套断言（test/TestApi.java），确保「文档结论 = 代码行为」。

## 二、实测可用的官方公开接口

| 能力 | 端点 | 方法 | 实测结果 |
| :-- | :-- | :-- | :-- |
| 歌单元数据 + 歌曲列表 | /api/v6/playlist/detail | POST form(id,n,s) | 200，热歌榜返回 200 首完整字段 |
| 歌曲详情（批量） | /api/song/detail?ids=[...] | GET | 200，单次 200 首可用 |
| 专辑详情 | /api/album/{id} | GET | 200，含曲目列表 |
| 音频播放源 | /api/song/enhance/player/url?ids=[id]&br=128000 | POST form | 200，**部分**曲目返回完整 mp3 地址 |
| 歌词 | /api/song/lyric?os=pc&id=..&lv=-1&kv=-1&tv=-1 | GET | 200，返回 LRC / 翻译 / 逐字 |
| 搜索 | /api/search/get | POST form(s,type,limit) | 200，返回歌曲列表 |

请求头需要 Referer: https://music.163.com/，无需登录、无需 Cookie、无需加密参数（未使用 weapi/eapi 加密协议）。

## 三、能力不等价：必须分开判断

| 能力 | 是否可得 | 依据 |
| :-- | :-- | :-- |
| 歌曲信息 | 是 | 公开接口直接返回 |
| 专辑封面 | 是 | al.picUrl，CDN 支持 https |
| 歌词 | 是 | lrc / tlyric / yrc 三个字段 |
| 播放信息（是否可听、音质） | 是 | 返回 level / br / fee / code |
| 音频文件下载 | **部分** | 接口返回 url 才有；否则 code=-110（版权）、404（无资源）或 fee=1（会员） |

**关键结论：能解析信息 ≠ 能下载音频。** 本工具的下载能力完全取决于平台是否给当前匿名请求返回播放源。

## 四、真实下载验证

对「起风了」(id 1330348068) 实测：

- 平台返回 size = 4.97 MB，br = 128000，type = mp3
- 实际下载 5,214,920 字节，与平台声明大小一致（误差 < 1%）
- 由码率反推时长 326s，与歌曲元数据 dt = 326s **完全一致**
- 文件头为 ID3 / MPEG 帧同步，可正常播放

结论：返回的是**完整曲目**，不是试听片段。同批测试中「海阔天空」(-110)、「晴天」(404)、「我记得」(-110) 均无可用源，应用会标记原因而不是伪造成功。

## 五、不可用方案（已明确排除）

| 方案 | 不采用原因 |
| :-- | :-- |
| weapi/eapi 加密接口 + 匿名登录 | 目标是拿会员曲目地址，实质是绕过版权，需求明令禁止 |
| 第三方解析站 / 镜像 API | 不稳定、来源不明，需求禁止当作稳定服务 |
| 把试听片段当完整音频保存 | 属于伪造结果 |
| 伪造 Cookie / token / 设备指纹 | 属于伪造身份 |

## 六、技术选型与理由

| 决策 | 选择 | 理由 |
| :-- | :-- | :-- |
| 语言 | Kotlin（业务）+ HTML/CSS/JS（界面） | 目标环境只有本地 JDK/kotlinc/aapt2 工具链，无 Gradle、无 AndroidX；WebView 承载界面可零依赖实现精细视觉，逻辑与 UI 解耦 |
| 网络 | java.net.HttpURLConnection | 不引入 OkHttp 依赖，避免 AAR 解析 |
| 存储 | SQLite（SQLiteOpenHelper） | 系统内置，支持版本迁移 |
| 并发 | ThreadPoolExecutor + 自建调度器 | 无协程库依赖，状态机完全可控 |
| 元数据 | 自写 ID3v2.3 写入器 | 无第三方库；写前备份，失败回滚 |
| 签名 | apksig（ApkSigner） | 生成 v1+v2 签名，Android 11+ 可安装 |

## 七、风险与应对

| 风险 | 应对 |
| :-- | :-- |
| 接口字段变化 | 解析一律 optXxx 带默认值，单曲失败不影响整批 |
| 平台收紧匿名播放源 | 如实显示「无法获取」并记录原因，不做降级伪装 |
| 公共目录写入 | 申请 MANAGE_EXTERNAL_STORAGE，未授权时回落 Download 子目录并提示 |
| 大歌单（1000+） | 列表分页渲染（每页 200），详情分批 200 首拉取 |
| 进程被杀 | 任务状态持久化到 SQLite，重启恢复为「已暂停」等用户确认 |

## 八、第二阶段调研（GitHub + v1 接口）

### 8.1 去了哪些地方

| 来源 | 结论 |
| :-- | :-- |
| GitHub Binaryify/NeteaseCloudMusicApi（★30224） | 社区最大的网易云 Web 接口封装；核心是同一批 music.163.com 端点，加上 weapi/eapi 加密与登录代理 |
| GitHub NeteaseCloudMusicApiEnhanced/api-enhanced（★2211） | 同上思路的分支 |
| 项目 docs 索引 | 确认 /song/url/v1 支持 level 参数（standard/higher/exhigh/lossless）|

### 8.2 实测验证（本机真实请求）

| 端点 | 结果 |
| :-- | :-- |
| /api/song/enhance/download/url?br=320000 | 免登录返回 url=null（官方下载按钮需要登录态）|
| /api/song/enhance/player/url/v1?level=exhigh | **返回 320k 完整音频，13,037,236 字节（≈326s）** |
| /api/song/enhance/player/url/v1?level=lossless | 平台降级为 exhigh（匿名无无损）|
| 同一批 6 首歌对比 | 旧接口高音质 4/6 → v1 接口高音质 5/6 |

### 8.3 关键发现：会员曲目只给试听

`freeTrialInfo` 非空即代表试听片段。「海阔天空」「晴天」等曲目返回的 url 只有 0.5~0.7 MB，若直接保存就是伪造成完整歌曲——这正是需求里明令禁止的。v1.3 已在解析、下载、落盘三层拦截。

### 8.4 仍然不做的事

- 不上 weapi/eapi 加密协议（那是为了拿会员音源，性质等于绕过版权）
- 不内置任何账号 Cookie / token 池 / 匿名 VIP 方案
- 不接第三方解析站
- Cookie 必须是用户自己的登录态，且只能拿到该账号本就拥有的权益
