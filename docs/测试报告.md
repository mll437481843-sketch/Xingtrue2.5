## 六、已知限制（非缺陷）

1. 会员/付费/版权受限曲目无法获取音频，应用明确标记「无法获取」并记录原因，这是平台授权限制。
2. 无损/320k 是否拿到取决于平台对匿名请求的返回，界面展示实际返回的 level。
3. 本地音乐库列表不逐条渲染内嵌封面（大数据量下的性能取舍），仅标记「缺封面」，可通过 library.cover 接口单曲查看。
4. 数据库当前为 v1 结构，onUpgrade 已留迁移入口，后续加表需补迁移脚本。
5. 目录（文件夹）无法用系统应用直接打开，界面会显示绝对路径；单个文件可通过 FileProvider 交给系统播放器打开。

## 七、装前 ART 级校验的尝试记录

| 尝试 | 结果 | 说明 |
| :-- | :-- | :-- |
| 设备自带 dalvikvm（ART 2.1.0 arm64）直接加载 APK 内的类 | 进程 Aborted | dalvikvm 需要完整 boot image 与主类入口，命令行方式无法直接验证应用类 |
| dex2oat 预编译校验 | 不可用 | /apex/com.android.art/bin 下没有 dex2oat 二进制（系统未暴露） |

因此 dex 合法性依据为：R8/D8（Android 官方 dexer）产出无错误 + aapt2 解析包结构通过 + 同一份 Kotlin 字节码在 JVM 上 20 项断言全过。真机首次安装后请优先跑「关于 → 运行自检」。
